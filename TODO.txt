Phase 10 — Build the Seattle Impact Engine

This is the secret sauce.


Create an ImpactEngine.

It should analyze:

transit disruptions
sporting events
concerts
public events
weather
traffic incidents

Calculate an overall Seattle transportation impact score from 0–100.

Categorize it:

0–24 = LOW

25–49 = MODERATE

50–74 = HIGH

75–100 = SEVERE

Explain which factors contributed to the score.

So instead of:

Mariners game

you can tell the user:

HIGH IMPACT

Mariners game + Link delays + downtown concert

That's much more useful.

Phase 13 — Lock screen
